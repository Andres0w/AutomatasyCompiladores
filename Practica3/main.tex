\section{1. Introducción}
    \large Los Automatas Finitos son maquinas teoricas que cambian de un estado a otro, dependiendo de la entrada recibida de esta. Su salida es limitada, donde dependiendo de la entrada que se le ha dado, decide si es \textbf{Aceptada}, o \textbf{No Aceptada}

    \large Para esta practica, se creara un Autómata Finito Determinista a traves de codigo, donde se definiran cada una de sus caracteristicas, como sus elementos, funciones de transición y estados finales/iniciales

\section{2. Marco teórico}

# Importacion de libreria
from automata.fa.dfa import DFA

# Creacion del automata
automata = DFA(
    # Alfabeto de entrada
    input_symbols={'0', '1'},
    # Conjunto de estados
    states={'q1', 'q2', 'q3'},
    # Estados de transicion
    transitions={
        'q1': {'0': 'q1', '1': 'q2'},
        'q2': {'0': 'q3', '1': 'q2'},
        'q3': {'0': 'q2', '1': 'q2'}
    },
    # Estado inicial
    initial_state='q1',
    # Estado final
    final_states={'q2'}
)
\end{lstlisting}

Con este codigo, nuestro automata tiene lo necesario para ejecutarse, pero aun falta algo, la funcion para darle cadenas y regresar una instruccion a partir de esto

\begin{lstlisting}
# Funcion para entrada de caracteres en el automata finito determinista
def leerentrada(AFD):
    try:
        while True:
            # Entrada de caracteres, Aceptado si es valido, Rechazado si falla
            if AFD.accepts_input(input("Entrada: ")):
                print("Aceptado")
            else:
                print("Rechazado")
    except KeyboardInterrupt:
        print("")

leerentrada(automata)
\end{lstlisting}

\section{5. Cuestionario}

\textbf{¿Qué paradigma de programación utilizaste para la implementación del AFD?, ¿Cuáles elementos 
del lenguaje de programación utilizaste? } \\
La programacion imperativa, y en el lenguaje de programacion, se utilizaron los elementos de funciones, paquetes, y variables \\
\textbf{¿Qué estructuras de datos utilizaste para implementar los componentes del AFD? } \\
Clases formadas por un paquete externo (automata-lib) \\
\textbf{¿Qué elementos del lenguaje de programación te permitieron implementar las funciones de transición?, ¿cuáles son las limitaciones del programa que construiste? } \\
Los paquetes y las clases, asi como las funciones; una de las limitaciones es que el programa necesita cambiar de codigo para cambiar el AFD que se usa, asi como que puede fallar debido a caracteres especiales en la terminal \\
\textbf{¿Qué condiciones se deben cumplir para que el programa pueda evaluar cualquier AFD?} \\
Editar el codigo fuente para cambiar los elementos del AFD completo, ya que no permite la edicion en el tiempo de ejecucion
